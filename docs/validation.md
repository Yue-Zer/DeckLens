# DeckLens 浏览器版验证记录

验证日期：2026-11-11。环境：Windows、Node.js 24.19.0、npm 11.17.0。测试使用合成文档、临时数据目录和模拟模型服务，没有使用私人文档或真实 API Key。

| 检查 | 结果 |
| --- | --- |
| `npm test` | Core 30/30；HTTP/阅读集成 16/16，全部通过 |
| `npm run typecheck` | server、web、core 均通过 |
| `npm run build` | Core、server 与 Vue/Vite 生产构建通过 |
| `npm run check:architecture` | 架构类型检查通过；schema 测试 10/10 |

自动测试覆盖文件哈希去重、Markdown/TXT/PPTX 解析、内容来源顺序与图片归属、章节调整和重解析保护、SQLite 迁移、探索节点与引用持久化、模型适配与密钥隔离、来源校验、标注几何数据及错误反馈。模型交互使用本地模拟服务，不代表真实第三方账号或模型已验证。

## 浏览器阅读检查

本机浏览器访问本地服务 `http://127.0.0.1:4281/`。测试数据目录位于系统临时目录 `%TEMP%\decklens-reading-ui-20261111`。

| 项目 | 结果 |
| --- | --- |
| Markdown 导入与阅读 | 标题、段落、列表、表格、代码、备注、行号和本地图片可显示 |
| TXT 导入与阅读 | 文档列表、段落和目录行为由集成测试覆盖 |
| 重复导入 | 相同 Markdown 按内容哈希去重；更名不产生重复文档 |
| 目录跳转 | 点击章节可定位正文；读取与来源顺序由集成测试覆盖 |
| 无模型状态 | 文档、目录和本地标注不依赖模型；AI 操作要求先配置模型。底部全局提问框仍是禁用占位 |

| 响应式宽度 | 1920、1440、1280、375 CSS px 检查中页面根节点无横向溢出；窄屏使用单栏抽屉 |

上述浏览器手工检查记录针对基础阅读路径。当前源码还集成了供应商设置、术语锚点、右侧层级探索以及画笔/套索 UI；后端行为和数据持久化由自动测试覆盖，但本记录没有使用真实远程模型逐项手工验收这些 UI 交互。

## 当前范围与限制

- 浏览器导入并原生解析 Markdown、TXT、PPTX。PPTX 的 OOXML 顺序、备注和图片归属由 Core 测试覆盖。
- 当前前端提供多供应商设置、术语点开探索、深挖/关联/分叉节点、引用跳转、手动笔记、正文标注和套索提问入口。AI 操作需要有效模型配置；没有模型时阅读和本地笔记仍可用。
- 探索回答由本地文档检索提供来源引用；没有足够相关证据时会明确说明。第三方模型行为及其数据保留政策由对应供应商决定。
- 底部全局提问输入框尚未接入；提问从术语、探索节点或套索操作发起。Anthropic Messages 仅预留，当前不能调用；探索面板不显示逐 token 流式输出。
- PDF、DOCX 原生解析、扫描件 OCR、翻译尚未实现。Markdown 解析只覆盖列出的常见结构，不是完整 CommonMark 排版器；复杂 PPTX 图表、SmartArt 和原版式重建也未完整支持。
- 超长阅读区尚未做虚拟列表；百页级文档的浏览器内存和交互性能仍需专项测量。
- 当前验证针对 Windows 本地浏览器形态，不代表 Electron、无 Node 的 EXE、跨操作系统或真实远程模型服务已通过验收。
